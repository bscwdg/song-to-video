# 层叠剪纸视觉 DNA

## 1. 材质

| 项 | 规则 |
|---|---|
| 纸面 | 哑光、平面、带极轻纤维；禁止镜面高光、塑料反射 |
| 纸边 | 不规则、略毛糙；主要轮廓可用 4–10px 位移 |
| 叠层 | 每层之间有方向一致的阴影，阴影颜色偏冷、不要纯黑 |
| 透光 | 灯笼、月亮、虹膜使用暖色 glow；glow 只做局部，不铺满全屏 |
| 颗粒 | 全片轻颗粒 + 极细纤维，强度保持稳定，不随镜头闪烁 |
| 插画 | 平涂为主；同一角色/道具在所有镜头保持一致 |

## 2. 色彩

不要固定一套“纸片滤镜”。让色彩承担叙事弧：

- 开场：夜蓝、月黄、纸白。
- 孤独：深蓝黑 + 一点暖灯。
- 回忆：冷绿灰逐渐转暖琥珀。
- 高潮：海蓝、泡沫白、月金、鲸墨。
- 人群：粉灰黄昏 + 深梅色剪影。
- 分离：藕粉天空 + 深蓝海面 + 纸幕暗边。
- 感谢：黄土、赭石、金橙。
- 主观：瞳孔琥珀 + 深青。
- 尾声：回到夜蓝与月黄，但亮度降低、纸层减少。

色彩规则：一个镜头最多 2 个高饱和色，其他都压低。不要让粉、金、青三色同时抢主体。

## 3. 镜头语言

- 用“纸层”代替 3D 纵深：前景纸屑/纸草、中景角色、后景月亮与云。
- 默认 35–70mm 的平面构图感；用缩放、平移、倾斜制造体积，不用真的 3D 旋转。
- 角色近景要占画面高度 35%–65%；远景要保留足够负空间。
- 镜头运动必须服务于情绪：拉远=孤立，推进=进入内心，上摇=升华，横移=时间流逝。
- 每镜至少有一次“有重量的动作”：浪拍、纸幕裂开、灯笼升起、虹膜推进。

## 4. 转场语法

| 转场 | 从哪来 | 适合 |
|---|---|---|
| 浪脊擦镜 | 前镜浪尖扫过画面 | 进入下一片海/下一拍 |
| 撕纸缝 | 画面中缝自然裂开 | 分离、时间跳切 |
| 纸页翻落 | 一层纸从上方落下 | 段落结束 |
| 孔洞/虹膜扩张 | 月洞、眼睛、灯笼孔洞扩大 | 进入主观/回忆 |
| 剪影对切 | 同一轮廓从船变鲸/从云变山 | 同义意象 |
| 硬切 | 鼓点 | 全片默认 |

禁止：默认交叉淡化、纯黑场、全屏白光闪、3D 翻页插件感。

## 5. 角色

- 默认用剪影 + 1–2 个精确可读特征（提灯、围巾、发髻、裙摆）。
- 角色不能只换颜色，要换姿势与朝向。
- 男孩提灯的手臂、女孩挥手的手臂要在所有镜头保持同一侧。
- 纸偶要有 idle：呼吸、船体浮沉、灯焰抖动、纸角微卷。
- 参考“低多边形纸偶”时要保留手工感，不要做成塑料玩具。

## 6. 纸感与可读性

- 主体与背景至少差 25% 明度，或差 1 个明显色相。
- 人物脸部若没有五官，用姿态和道具表达情绪。
- 纸屑/星星只做节奏点缀，数量不要淹没主语。
- 字幕与主体不同层；字幕一般放在底部 15% 内，不压关键动作。

## 7. 反模板

以下任一出现就要改：

- 九个镜头都在蓝底 + 月亮 + 小船；
- 每镜都在缓慢推镜，没有景别/视角变化；
- 所有元素同时淡入淡出；
- 把“剪纸”做成矢量图标，没有纸边、阴影、层间关系；
- 所有节拍都加同一个“叮”；
- 结束前突然出现与全片无关的通用片尾卡。
