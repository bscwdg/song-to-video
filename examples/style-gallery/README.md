# Style gallery

五个 style pack 的 20 秒预览。每个风格 4 秒，硬切。

```powershell
npm install
npm run start
```

渲染：

```powershell
npm run typecheck
npm run render
```

## 顺序

1. `painted-animation` · 手绘水彩动画
2. `kinetic-reel` · 动态字体 Reel
3. `ink-wash` · 水墨国风
4. `flat-explainer` · 扁平插画科普
5. `pixel-8bit` · 8-bit 像素

这些是 **preview 级风格包**：能用于预览方向、选择风格和写 storyboard，但还没有像 `papercut-mv` 一样完整的场景库与生产验收。
