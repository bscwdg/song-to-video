# Shot planning

镜头数是**结果**，不是目标。

不能先定“4 镜”或“9 镜”再往里塞歌词，也不能为了显得丰富而机械切碎。镜头数由这些因素共同决定：

- 片段时长
- 歌词行数与乐句边界
- 段落结构（主歌 / 副歌 / 桥段 / 器乐）
- 每句歌词是否属于同一叙事单元
- 能量与拍点密度
- 构图和动作的复杂度
- 是否需要回环、留白或长镜头

## 规划顺序

1. 先按 `intent` 把歌词分组，每组是一个候选镜头。
2. 相邻两组合并：如果它们讲同一件事，且画面可以在同一构图里完成内部变化。
3. 拆开一组：如果一组里出现两个不同动作、时间跳跃或主体更换。
4. 把切点吸附到真实拍点或小节线。
5. 检查每个镜头是否有一个明确动作，以及是否需要内部 phase。

## 时长只是约束，不是配额

下面的区间只用于发现明显不合理，不是必须遵守的镜头数表：

- `< 1.2s`：只适合标点式收尾或极短转场，正片镜头通常太短。
- `1.2–3s`：高能量、快切或短副歌可用，整片连续使用容易碎。
- `3–8s`：常见叙事镜头区间。
- `> 8s`：必须有两个以上可见内部 phase/transform，否则拆镜。

平均镜头长度也只作为检查：

- 歌词密集、节奏快：平均约 3–5s。
- 中等密度：平均约 4–7s。
- 器乐、环境、慢歌：平均约 6–10s。

这些区间是 sanity check，不是硬编码。真正决定镜头数的是语义单元。

## 例子

- 16 秒、4 句、4 个明确语义单元：4 镜可以成立。
- 32 秒、18 句、副歌重复两遍：4 镜通常太少，优先 5–8 镜；如果重复段有完整视觉仪式，也可以保留 2 个较长镜头。
- 60 秒、段落完整、歌词较多：通常 8–15 镜。
- 120 秒以上：按叙事单元扩展，不要沿用短视频镜头数。

## 禁止

- 先定镜头数，再按镜号轮转画面。
- 用镜头数衡量成片质量。
- 把一个连续动作切成很多没有意义的短镜。
- 为了“每镜不同”而让每镜都换主体、色板和机位。
- 为了“长镜头高级”而让一个 10 秒镜头没有任何内部变化。

## 验收

每个镜头问三个问题：

1. 为什么要在这里切？
2. 这镜内部发生了什么变化？
3. 如果换到前后镜头，语义会不会损失？

答不出来，就合并、拆分或重写分镜。
