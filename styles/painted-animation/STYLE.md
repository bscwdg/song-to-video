# 手绘水彩动画

来源：`opus-video-skills/painted-animation`。

## 观感

整帧像纸上的水彩和墨线。颜色有轻微渗化，线条会“沸腾”，角色不是几何图标，而是被画笔一笔笔画出来的。

## 适用

- 情绪型歌词
- 角色关系、回忆、告别
- 需要温度和手工感的叙事

不适用：科技发布会、数据密集解释、强赛博感。

## 色板

- 纸：`#f5ead5`
- 珊瑚：`#d9765f`
- 灰蓝：`#5c8f9b`
- 芥末黄：`#d9a441`
- 墨：`#20252a`

## 动作

- 水彩从中心或笔触方向晕开
- 墨线以 2–3 帧的微小抖动保持手绘感
- 角色先出剪影，再上一层颜色
- 转场用笔刷扫过、纸面擦除，不用通用叠化

## 镜头

- `watercolor-world`：大片留白中的水彩景物
- `character-beat`：角色动作与表情
- `ink-reveal`：用墨线揭示歌词中的物件

## 禁止

- 霓虹发光
- 3D 材质
- 纯黑纯白背景
- 过度精确的 UI 元素
